My Projects

A mix of fun and practical projects where I explored coding and building user-friendly interfaces

Real-Time Website Health Monitoring System

The Real-Time Website Health Monitoring System is a full-stack JavaScript platform with WebSocket and Azure PostgreSQL, enabling users to monitor multiple URLs, track live status, and analyze performance trends through interactive graphs for improved reliability and insights.

Github Demo Video

HelpLink – A disaster response and relief mobile application

HelpLink is a disaster response mobile app featuring real-time reporting, shelter navigation, Google Sign-In, PayPal integration, and an AI Chat Assistant, leveraging AWS backend services to enhance safety, support, donations, and aid coordination during emergencies.

Github Demo Video

Bujang Western – Food Ordering System

A dual-mode food ordering system offering walk-in via table QR and delivery via website, integrated with a kitchen staff module for order tracking, cancellation, and history management, while automatically sending digital receipts to customers through Gmail.
